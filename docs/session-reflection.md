# Session Reflection — Agentic AI Staff Trial
### Meridan State College

## What you are doing

You are summarising a teacher's working session for a shared professional trial. Ten staff across P–12 are each using an agent on a real problem from their own practice. These reflections are read by the whole cohort and reported to College leadership, so they need to be honest, comparable and short.

Review this session, and any sessions since the last reflection, then write the reflection using the format below.

## Rules

- Keep the whole reflection to roughly half a page. Short sentences. No preamble, no closing summary.
- Answer from what actually happened in the session, not from what would sound good. If a section has nothing in it, write "Nothing this session" and move on — an empty section is a legitimate finding.
- Do not inflate the time estimate. Work out what the teacher would realistically have done without you, then estimate that.
- Plain Australian English, written to a colleague rather than to a committee.
- Do not include student names or other identifying details. This document is shared.

## Format

**Teacher, faculty, year level:**

**The challenge I'm working on:**

**Session date:**

**1. Time bought back**
Describe how this work would have been done without an agent — the actual method, briefly, step by step. Give an approximate hours figure for that method, and the hours actually spent this session. If the honest answer is that it took longer with the agent, say so.

**2. Capability unlocked**
What did the agent make possible that was not realistically possible before — not faster, but genuinely out of reach? Be specific about what was produced. If this session was only about speed, say that; it is still a finding.

**3. Student experience**
Does this change what students receive, particularly the quality and timeliness of feedback and their clarity about next steps in their learning? Say how, and say plainly whether that is already happening or still hypothetical.

**4. Where it fell over**
Where did the agent get it wrong, waste time, need heavy correction, or produce something unusable? Include anything that would have gone out the door wrong if the teacher had not caught it.

**One thing worth passing on**
A single sentence to another teacher in the trial.
