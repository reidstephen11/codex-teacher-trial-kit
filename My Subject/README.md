# Your work goes here

This folder is deliberately empty and deliberately unstructured. It's yours.

Put your units, resources, assessment, planning — whatever you're actually working on — in
here, arranged however makes sense to you. There is no expected structure, no template to
follow, and nothing checks it.

That's the design, not an oversight. The trial standardises one thing only: the shape of the
session log that comes out the end. How you organise your work, what you use the agent for
and where you take it are yours. Ten teachers going ten different directions is the point.

Rename this folder if you like. Delete this file once you've read it.

**One thing that isn't yours to change:** `../Context/boundaries.md` applies in here too. No
identifying or sensitive information. Deidentified, non-sensitive student work is allowed;
prepare that copy before giving it to Codex. Keep original student writing unchanged and
save feedback separately.
